Writeup for Cypher - a HackTheBox medium lab.

Enum

Same as Heal, only SSH and webservice are available.

Bruteforcing directory results an interesting endpoint: /testing , with a jar file. Let’s decompile it.

Cypher APOC → Command Injection RCE

Upon decompiling the jar file, we know that the Graph ASM has Neo4j as its backend. Neo4j use Cypher as its query language, and APOC to extend its functionalities. Below is the decompiled result, pretty clear.

We now know that the remote APOC instance has a backdoor function integrated, which executes a curl to an URL to get its status code. If we can call it somewhere in the application, we can achieve RCE using Command Injection.

For how to call it, take a look at the Cypher Injection Cheat Sheet - Pentester Land. There is only the login page to inject, and it just works. The query we are injecting to is: MATCH (u:USER) -[:SECRET]-> (h:SHA1) WHERE u.name = '<username>' return h.value as hash.

Using the CALL and UNION keyword, let’s craft a Cypher Injection that calls the backdoor function to exploit it.

This injection works and called the backdoor function, a localhost listener at port 1337 will catch the curl request.

This injection create a Bind Shell on the target, we can connect to it using ncat 10.10.11.57 1337.

Then we got our Bind Shell as neo4j on the target. /etc/passwd shows a user named graphasm. Its password can be found in neo4j bash history (always spray password whenever you get it).

Then we got the user flag!

BBOT → Root flag

We can run bbot with sudo privilege. For more detail about it, here: blacklanternsecurity/bbot: The recursive internet scanner for hackers.

So how can we exploit BBOT to read the root flag? By using some option that reads a file and leak it in debug mode! Just one simple command and we are done.

Still, we just have arbitrary file read on the system, but not the full root privilege. Further escalations to achieve full root is an exercise left for the readers.
